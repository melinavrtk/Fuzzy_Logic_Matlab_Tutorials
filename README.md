# Fuzzy Logic MATLAB Tutorials 

This repository contains MATLAB scripts developed for educational purposes, originally presented during IEEE Student Branch tutorials. The goal is to help students understand the mathematics behind Fuzzy Logic Systems and implement them from scratch.

## 1. Fuzzy Relation & 3D Visualization (`fuzzy_relation_3d.m`)
This script demonstrates how to compute and visualize a fuzzy relation between two distinct universes of discourse (e.g., VO2max and Training Level). 
* Utilizes **Gaussian membership functions**.
* Explains the concept of **Ruspini partitions** (50% overlap).
* Computes the relation matrix using the **Minimum T-norm**.
* Generates a **3D Surface Plot** (`surf` and `meshgrid`) to visually represent the relation space.
